# Музыка

Положите сюда треки (`.mp3`, `.ogg`, `.m4a` — что угодно, что играет браузер) и
опишите их в `manifest.json` рядом:

```json
{
  "tracks": [
    { "file": "neon-drive.mp3", "title": "Neon Drive", "scene": "game" },
    { "file": "menu-theme.mp3", "title": "Standby", "scene": "menu" },
    { "file": "duel.mp3", "title": "Duel", "scene": "versus" }
  ]
}
```

`scene` — где играет трек: `menu`, `game`, `versus` или `any` (по умолчанию —
везде). Треков на одну сцену может быть сколько угодно, игра выбирает случайный
и переключается на следующий, когда текущий закончился.

Файла `manifest.json` может не быть вовсе — тогда музыка просто выключена, а
звуковые эффекты (они синтезируются кодом) работают как обычно.
