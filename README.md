# NEONOID

Арканоид с roguelite-прогрессией: опыт и усиления внутри забега, суперудары с
энергетической шкалой, редактор уровней и два режима PvP на одном компьютере.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сборка продакшен-версии (статические файлы в `dist/`, без зависимостей в рантайме):

```bash
npm run build
```

## Режимы

| Режим | Что это |
| --- | --- |
| **Кампания** | 100 уровней: первые 10 нарисованы вручную, 11–80 собирает сидированный генератор с растущей плотностью и скоростью, 81–100 — полностью случайный хардкор. Опыт, усиления, жизни и счёт переносятся между уровнями. |
| **Выбор уровня** | Старт с любого из 100 уровней; пройденные отмечаются, цвет плитки показывает сложность. |
| **Свои уровни** | Тот же забег, но по уровням из вашей библиотеки (редактор). |
| **Дуэль 1 на 1** | Общее поле: ракетки сверху и снизу, кирпичи посередине, мяч один. Пропустил — гол сопернику. Матч до 5 голов. |
| **Раздельный экран 1 на 1** | Два независимых поля рядом. Каждый суперудар бьёт и по сопернику; зачистка своего поля отправляет сопернику два ряда мусорных кирпичей. Побеждает тот, у кого остались жизни. |
| **Редактор уровней** | Сетка 12×18, палитра кирпичей, тест в один клик, сохранение в браузере, импорт/экспорт JSON. |

## Игроки и сохранения

До 15 профилей, у каждого свой уровень, опыт, суперы, настройки и статистика.
Профиль выбирается кнопкой «Сменить игрока» в главном меню.

У каждого профиля есть **один автосохраняемый забег кампании**. Он пишется
после каждого пройденного уровня — в этот момент мяч не в полёте и состояние
однозначно. В меню появляется карточка «Продолжить забег» с уровнем, счётом и
жизнями. Поражение сейв не стирает: с экрана «Забег окончен» можно вернуться на
последний сохранённый уровень со всеми усилениями. Сейв очищается только победой
над сотым уровнем.

Первый профиль (в том числе созданный при переносе старого сохранения) —
**админский**: все суперы и уровни открыты, доступны управление чужими
профилями, читы и отладка:

| Клавиша | Действие |
| --- | --- |
| `G` | бессмертие |
| `H` | +1 жизнь |
| `J` | зарядить суперудар |
| `K` | пропустить уровень |
| `L` | выдать элементальный шар (по кругу) |
| `O` | отладочная панель: состояние, сид, кирпичи, скорость мяча, счётчики |

Админ также может открыть в редакторе любой уровень кампании, изменить его и
записать обратно. Уровни 11–100 выводятся из сида, поэтому правка хранится
отдельным переопределением — кнопка «Сброс» возвращает исходный уровень.

## Развилки

Кампания — не прямая линия, и билд внутри забега тоже.

**Развилка пути.** Каждые 10 уровней забег упирается в развилку: следующий
десяток перестраивается под выбранный маршрут — своя палитра кирпичей, своя
плотность, скорость и награды.

| Маршрут | Поля | Награда |
| --- | --- | --- |
| ⛓ Литейная | сталь, неразрушимые, взрывные; мяч медленнее | плотные уровни и много очков |
| ❉ Оранжерея | регенераторы, золото, подарки | +40% опыта |
| ☢ Пустошь | хаос-паттерны, разогнанный мяч | +50% к выпадению бонусов |

Выбранные маршруты пишутся в автосохранение, так что забег восстанавливается
ровно тем, каким его вели.

**Развилка билда.** На 5-м уровне мастерства вместо обычного усиления
предлагается специализация на весь забег. Она не только даёт мгновенный эффект,
но и втрое повышает шанс встретить в дальнейших драфтах усиления своей школы.

| Специализация | Что даёт |
| --- | --- |
| ↑ Артиллерист | штатный лазер, двойной урон выстрелов, +35% энергии супера |
| ✷ Элементалист | элементальные шары держатся вдвое дольше, +1 урон, +40% бонусов |
| ▭ Страж | +2 жизни и +2 барьера сразу, ракетка шире, мяч послушнее |

## Новая кампания и витки (New Game+)

Уровень профиля, опыт, суперы, рекорды и статистика живут отдельно от забега,
поэтому кампанию можно начинать заново сколько угодно раз, ничего не теряя.
Кнопка «Новая кампания» стартует чистый забег (автосохранение при этом
перезаписывается — об этом предупреждает подсказка).

Прохождение сотого уровня открывает следующий **виток**: за каждый виток мяч
быстрее на 8%, а опыт идёт с прибавкой 25%. Номер витка виден в главном меню,
и в него можно войти сразу с экрана победы.

## Настройки забега

На экране кампании перед стартом выбираются:

- **Жизни** — 1 (хардкор), 3, 5 или 9.
- **Скорость игры** — ×1, ×2 или ×3. Множитель ускоряет игровые часы целиком:
  мяч, ракетка, падающие бонусы и все таймеры — так что игра остаётся собой,
  просто быстрее. Переключается и на ходу клавишей `F`, текущее значение видно
  в HUD рядом с номером уровня.

Обе настройки запоминаются в профиле и действуют также в PvP-режимах.

## Управление

**Одиночная игра:** мышь или `A`/`D` (`←`/`→`) — ракетка, `Пробел` — запуск мяча
и выстрел лазером, `Shift` — суперудар, `1`/`2`/`3` — выбор усиления,
`F` — скорость игры, `Esc` — пауза.
Управляет то устройство, которым воспользовались последним:
нажали клавишу — ведёт клавиатура, двинули мышь — снова мышь.

**PvP:** игрок 1 — `A`/`D`, `W` (огонь), `S` (супер), усиления `1`/`2`/`3`;
игрок 2 — `←`/`→`, `↑` (огонь), `↓` (супер), усиления `8`/`9`/`0`.

## Система опыта

Опыт даёт каждый разбитый кирпич; серия попаданий без потери мяча поднимает
множитель (до ×12, больше — с усилением «Серия»). Новый уровень мастерства
внутри забега останавливает игру и предлагает три усиления на выбор:
ширина и скорость ракетки, критический урон, магнит для бонусов, штатный лазер,
запасные жизни, нижний барьер и другие — всего 17 видов со стеками.

Опыт начисляется намеренно скупо (глобальный коэффициент `XP_RATE = 0.1` в
[progression.ts](src/core/progression.ts)): усиление — награда за длинную чистую
серию, а не за каждый экран.

После забега весь набранный опыт зачисляется в профиль (`localStorage`).
Уровень профиля открывает суперудары: «Разлом времени» с 3-го, «Сингулярность»
с 5-го.

## Элементальные шары

Отдельный класс бонусов перекрашивает мяч и меняет то, как он бьёт. Действуют
14–18 секунд, за две секунды до конца мяч начинает мигать белым.

| Шар | Цвет | Что делает |
| --- | --- | --- |
| Лава-болл | оранжевый | прошивает кирпичи насквозь и поджигает всё вокруг точки удара |
| Аква-болл | голубой | медленный и послушный, бьёт волной по соседям в ряду |
| Лазер-болл | зелёный | каждое попадание выпускает вверх два луча |
| Плазма-болл | фиолетовый | цепная молния на два ближайших кирпича |
| Войд-болл | индиго | тяжёлый: +2 урона, притягивает бонусы и доворачивает к кирпичам |

## Звук и музыка

Звуковые эффекты синтезируются в WebAudio прямо в коде
([sfx.ts](src/audio/sfx.ts)) — ни одного аудиофайла, ни загрузки, ни задержек;
высота звука разрушения растёт вместе с комбо.

Музыка подключается своими треками: положите файлы в `public/music/` и опишите
их в `public/music/manifest.json`:

```json
{
  "tracks": [
    { "file": "menu.mp3", "title": "Standby", "scene": "menu" },
    { "file": "drive.mp3", "title": "Neon Drive", "scene": "game" },
    { "file": "duel.mp3", "title": "Duel", "scene": "versus" }
  ]
}
```

`scene` — `menu`, `game`, `versus` или `any`. Треков на сцену может быть
сколько угодно, игра берёт случайный и переходит к следующему по окончании. Без
манифеста музыка просто выключена. Громкость эффектов и музыки настраивается в
меню «Звук и музыка».

## Суперудары

Шкала копится от урона и подобранных бонусов. В PvP каждый удар одновременно
бьёт по сопернику:

| Супер | Своё поле | По сопернику |
| --- | --- | --- |
| Плазменный залп | 5 секунд плазмы из ракетки | ряд мусорных кирпичей |
| Метеор | горящие мячи прошивают кирпичи | разгон мяча на 8 секунд |
| Разлом времени | замедление + широкая ракетка | инверсия управления на 5 секунд |
| Сингулярность | чёрная дыра перемалывает кирпичи | помехи на экране на 6 секунд |

## Формат уровня

Уровень — это JSON, который можно править руками; каждая строка `rows` — ряд
из 12 символов:

```json
{
  "id": "user-abc",
  "name": "Крепость",
  "rows": ["xxnnnnnnnnxx", "xnttttttttnx"],
  "ballSpeed": 1.05
}
```

Коды кирпичей: `.` пусто, `n` обычный, `t` прочный (2 удара), `s` стальной (3),
`x` неразрушимый, `e` взрывной, `r` регенерирующий, `g` золотой (тройной опыт),
`p` подарок (гарантированный бонус), `b` мусорный (прилетает в PvP).

## Устройство кода

```
src/core/     симуляция: арена, физика, кирпичи, бонусы, шары, опыт, суперы,
              генератор уровней, хранилище
src/render/   canvas-рендер, частицы, фон меню
src/game/     режимы: кампания, раздельный экран, дуэль, ввод, фиксированный шаг
src/editor/   редактор уровней
src/audio/    синтез звуков и музыкальный плеер
src/ui/       меню, выбор уровня, настройки звука, DOM-хелперы, стили
public/music/ ваши треки (см. README внутри)
```

Симуляция отделена от рендера и идёт фиксированным шагом 1/120 с с сидированным
генератором случайных чисел: при одинаковых входных данных результат
воспроизводится, поэтому обе половины PvP-матча честны, а сетевой режим можно
добавить поверх той же логики.
