# NEONOID

Арканоид с roguelite-прогрессией: опыт и усиления внутри забега, суперудары с
энергетической шкалой, редактор уровней и два режима PvP на одном компьютере.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сборка продакшен-версии (статические файлы в `dist/`, без зависимостей в рантайме):

```bash
npm run build
```

## Режимы

| Режим | Что это |
| --- | --- |
| **Кампания** | 100 уровней: первые 10 нарисованы вручную, 11–80 собирает сидированный генератор с растущей плотностью и скоростью, 81–100 — полностью случайный хардкор. Опыт, усиления, жизни и счёт переносятся между уровнями. |
| **Выбор уровня** | Старт с любого из 100 уровней; пройденные отмечаются, цвет плитки показывает сложность. |
| **Свои уровни** | Тот же забег, но по уровням из вашей библиотеки (редактор). |
| **Кооп на двоих** | Одно поле **вдвое шире** и две ракетки бок о бок. Мячи, жизни, опыт, усиления, суперудар и скиллы — общие: мяч упустил один, потеряли оба. Уровень кампании разворачивается на широкое поле зеркально. |
| **Гонка** | Настолка на 2–6 человек за одним компьютером: кубик, трасса из закрытых клеток и карты, которые ждущие игроки бросают прямо в чужой уровень. См. отдельный раздел ниже. |
| **Дуэль 1 на 1** | Общее поле: ракетки сверху и снизу, кирпичи посередине, мяч один. Пропустил — гол сопернику. Матч до 5 голов. |
| **Раздельный экран 1 на 1** | Два независимых поля рядом. Каждый суперудар бьёт и по сопернику; зачистка своего поля отправляет сопернику два ряда мусорных кирпичей. Побеждает тот, у кого остались жизни. |
| **Редактор уровней** | Сетка 12×18, палитра кирпичей, тест в один клик, сохранение в браузере, импорт/экспорт JSON. |

## Игроки и сохранения

До 15 профилей, у каждого свой уровень, опыт, суперы, настройки и статистика.
Профиль выбирается кнопкой «Сменить игрока» в главном меню.

У каждого профиля есть **один автосохраняемый забег кампании**. Он пишется
после каждого пройденного уровня — в этот момент мяч не в полёте и состояние
однозначно. В меню появляется карточка «Продолжить забег» с уровнем, счётом и
жизнями. Поражение сейв не стирает: с экрана «Забег окончен» можно вернуться на
последний сохранённый уровень со всеми усилениями. Сейв очищается только победой
над сотым уровнем.

Первый профиль (в том числе созданный при переносе старого сохранения) —
**админский**: все суперы и уровни открыты, доступны управление чужими
профилями, читы и отладка:

| Клавиша | Действие |
| --- | --- |
| `G` | бессмертие |
| `H` | +1 жизнь |
| `J` | зарядить суперудар |
| `K` | пропустить уровень |
| `L` | выдать элементальный шар (по кругу) |
| `O` | отладочная панель: состояние, сид, кирпичи, скорость мяча, счётчики |

Админ также может открыть в редакторе любой уровень кампании, изменить его и
записать обратно. Уровни 11–100 выводятся из сида, поэтому правка хранится
отдельным переопределением — кнопка «Сброс» возвращает исходный уровень.

## Активные скиллы

Два слота на клавишах `Q` и `E`, у каждого своя перезарядка и радиальный
индикатор в HUD. Скиллы открываются за уровень профиля, а внутри забега

Каждый ранг сокращает перезарядку на 15%.

| ∪ Магнетизм | притягивает мяч и бонусы | 60 с |
| ☄ Файрбол | прошивает колонну кирпичей; **на III ломает неразрушимые** | 60 с |
| ⇄ Телепорт | ракетка мгновенно под мячом | 25 с |
| ▭ Барьер | пол ловит мяч | 45 с |
| ◷ Стазис | мячи замедляются вдвое | 40 с |
| ◫ Двойник | зеркальная ракетка-призрак отбивает наравне с вами | 70 с |
| ⌁ Дрон | турель сама расстреливает кирпичи | 60 с |
| ⬢ Молот | следующий удар — пятикратный урон | 30 с |
| ⚡ Разряд | молния по пяти кирпичам | 35 с |

## Боссы

Каждый десятый уровень кампании — бой с боссом: отдельная сущность со шкалой HP,
которая двигается, стреляет и меняет поведение по мере смерти.

| Фаза | Что происходит |
| --- | --- |
| 1 · щит | Пока стоят кирпичи, босс неуязвим и только ходит из стороны в сторону |
| 2 · огонь | Щит пробит — босс стреляет вниз; попадание сминает ракетку на 5 секунд |
| 3 · ярость | Ниже 30% HP: тройные залпы, разгон и сброс мусорных рядов вниз |

Роспись боссов: **Страж** (10–30), **Ткач** (40–70), **Ядро** (80–90) и **DOH**
на сотом. Награда за победу — крупный опыт, +1 жизнь и гарантированный ранг
одного из ваших скиллов.

Мусорные ряды, которые босс роняет в третьей фазе, щит ему не возвращают —
иначе бой мог бы длиться вечно.

## Игра по локальной сети

На одном из компьютеров:

```bash
npm run lan
```

Команда собирает игру и поднимает сервер комнат. Он печатает адрес вида
`http://192.168.х.х:8080` — его открывают остальные в браузере, ничего
устанавливать им не нужно.

Что даёт сеть:

- **Ссылка вместо установки** — сервер раздаёт саму игру.
- **Комната** — все, кто открыл адрес, оказываются в одной комнате; экран «Сеть»
  показывает, кто подключён.
- **Чужой прогресс вживую** — режим, уровень, счёт и жизни каждого игрока
  обновляются в реальном времени.
- **Общая доска почёта** — результаты стекаются на сервер и расходятся по всем
  машинам; сервер хранит их в `server/data/hall.json`, так что таблица переживает
  перезапуск.

### Сетевой матч 1 на 1

На экране «Сеть», когда в комнате есть кто-то ещё, появляются кнопки матча:
один нажимает «Начать матч (я хост)», второй — «Присоединиться». Хост задаёт
сид, поэтому оба получают одинаковые уровни.

Играется это как раздельный экран, разнесённый на две машины: слева ваше поле,
справа — поле соперника, которое обновляется по сети. Суперудары и саботажные
шары летят на ту сторону так же, как в локальном PvP.

Каждая сторона считает **только своё** поле — ни шага в ногу, ни откатов. По
сети идут лишь атаки (редкие и не зависящие от порядка) и снимок поля для
отрисовки. Задержка может задержать атаку или на кадр состарить чужое поле, но
рассинхронизировать матч не может.

Без сервера (открыто файлом или с GitHub Pages) всё продолжает работать локально:
сеть просто отключена, а доска почёта синхронизируется между окнами на этом
компьютере.

**Публикация по ссылке в интернете.** В репозитории лежит workflow
`.github/workflows/pages.yml`: пуш в `main` собирает игру и публикует её на
GitHub Pages. Достаточно включить Pages в настройках репозитория (source —
GitHub Actions).

## Сюжет

Кампания рассказывает историю станции «Предел», чьё ядро закрылось изнутри и
застроило сотню отсеков блоками памяти. Повествование не мешает игре: тексты
появляются ровно там, где игра и так делает паузу.

- **Пролог** — перед первым уровнем нового забега.
- **Лор сектора** — на развилке, после выбора маршрута: у Литейной, Оранжереи и
  Пустоши своя история.
- **Смотрители** — реплика босса перед боем и строчка о его гибели в итогах
  уровня.
- **Финал** — что было в ядре, после сотого уровня.
- **Витки** — на каждом NG+ станция перезапускается со своей репликой.

Всё прочитанное собирается в **Хронику** (пункт меню): открытые записи можно
перечитать, неоткрытые видны как `???` и не спойлерятся.

## Гонка (настолка на 2–6 игроков)

Отдельный PvP-режим за одним компьютером. Все идут по общей трассе, но играют
по очереди: свой ход — короткий уровень против таймера, чужой — трансляция, в
которую вы бросаете карты. Ожидание перестаёт быть простоем, и в этом весь режим.

**Ход целиком:**

1. Игрок садится за уровень своей клетки. Обычный ход — **75 секунд и 2 жизни**,
   босс — **130 секунд и 3 жизни**. Таймер идёт только вниз; часы стоят, пока
   выбирается усиление.
2. Пока он играет, остальные бросают в него карты, а сам он собирает новые.
3. **Экран кубика**: кубик крутится, останавливается, показывает своё число
   крупно и со своей репликой — их по четыре на каждую грань. Ниже — что
   добавила игра: зачистил `+2`, успел с запасом времени `+2`, не потерял жизнь
   `+1`, серия от ×8 `+1`, «не успел» `−1`. Умер — ход сгорает, кубик не
   бросается вовсе.
4. **Экран хода**: фишка шагает по клетке за раз, и если под ней что-то есть —
   клетка открывается и срабатывает.

**Дистанция настраивается**: 20 (блиц), 50 (стандарт) или 100 клеток. Трасса
всегда растянута на всю кампанию, поэтому даже блиц кончается DOH — просто
уровни на нём скачут через пять-шесть номеров за клетку.

### Клетки закрыты

Примерно каждая третья клетка что-то делает, но **все они лежат рубашкой вверх**.
Клетка открывается, только когда на неё кто-то встал, и дальше светится своим
цветом **до конца матча и для всех**. Поэтому доска постепенно превращается в
известную местность — а вместе с этим начинают что-то значить карты `±1` к
кубику: когда провал на 17-й уже открыт, разница между пятёркой и четвёркой
перестаёт быть абстрактной.

| Клетка | Что делает |
| --- | --- |
| ➤ Прыжок | вперёд на 3–8 клеток |
| ▼ Провал | назад на 2–5 клеток |
| ◆ Рулетка | вперёд или назад на 4–10, поровну |
| ⇄ Обмен | меняет вас местами с ближайшим игроком |
| ⇑ Катапульта | вперёд на 6–12, но следующий уровень начнётся с помехой |
| ♥ Аптечка | +1 жизнь на следующий ход |
| ✚ Госпиталь | +3 жизни на следующий ход |
| ⏱ Хронометр | +30 секунд к следующему ходу |
| ⌛ Мытарь | −20 секунд на следующем ходу |
| 🎁 Тайник | две карты в запас |
| ⏮ Обрыв | обратно на старт |
| 🔄 Реверс | порядок ходов переворачивается до конца матча |

### Карты собираются, а не выдаются

Карты **не респаунятся по таймеру**: их зарабатывают своей игрой. На уровне
гонки падает капсула **★** — поймали, карта легла в запас (до 12 штук). За
зачистку дают ещё две, за босса три. Что накопили — тем и бросаетесь в чужие
ходы; первые три карты запаса лежат на ваших клавишах, и сыгранная карта просто
уходит, а на её место сдвигается следующая из запаса.

Пятнадцать карт, и главные из них — часы: ход идёт на убывание, поэтому секунды
дороже любого усиления.

| Помощь | Вред |
| --- | --- |
| ⏱ +10 секунд | ⌛ −10 секунд |
| ⏱ +15 секунд | ⌛ −15 секунд |
| ⁘ Мультимяч | ❄ Мороз |
| ♥ Жизнь | ↔ Зеркало |
| 🔥 Лава-болл | ▓ Помехи |
| ⬌ Опора (шире ракетка) | ▦ Стальной ряд |
| ⇢ Попутный ветер (+1 к броску) | ⌁ Глушилка · ⚓ Гиря (−1 к броску) |

Карта прилетает **мгновенно**, поэтому её цену определяет выбранная секунда:
мультимяч под потолком — подарок, он же на подаче — ничто.

**Защита.** Тот, кто играет, жмёт `R` и один раз за ход отбивает входящую карту.
Карта бросавшего сгорает всё равно — поэтому щит выманивают дешёвой картой, а
дорогую бросают следом.

**Альянсы.** Пакт заключается на экране трассы. Пока он держится, союзники не
могут бить друг друга, за каждый зачищенный союзником уровень вы получаете
карту, а **жизни, собранные с клеток, можно передать союзнику** — по одной или
все сразу. Разрыв стоит половины запаса карт и виден всем.

**Финал.** Последняя клетка — мега-босс DOH. Не добили — откат на 5 клеток и
гонка продолжается; добили — победа.

**Про сеть.** Режим сразу собран под то, что смотреть будут с чужих ноутбуков:
все правила лежат в [race.ts](src/core/race.ts) без единого обращения к DOM или
арене, а всё состояние гонки — это несколько чисел на игрока плюс байт на
клетку. Доска на экране хода не перерисовывается целиком: шаг фишки трогает
ровно две ячейки, и это то, что иначе дёргалось бы на слабой машине.

## Шары-дебаффы (только PvP)

В дуэли и на раздельном экране падают саботажные капсулы. Подобрали — ваш мяч
перекрашивается в её цвет, и **каждые несколько разбитых кирпичей** эффект
уходит сопернику. То есть давление зарабатывается игрой, а не удачным дропом; в
одиночной кампании такие капсулы не выпадают вовсе.

| Шар | Что достаётся сопернику | Кирпичей на заряд |
| --- | --- | --- |
| ❄ Мороз | ракетка еле ползёт, 6 с | 3 |
| ↔ Зеркало | управление перевёрнуто, 5 с | 4 |
| ⋯ Хрупкость | ракетка крошится с каждым отбитым мячом, 9 с | 4 |
| ⊗ Антимагнит | бонусы шарахаются от ракетки, 8 с | 3 |
| ▦ Сталь | ряд стальных кирпичей на поле | 6 |
| ▓ Помехи | поле заливает рябью, 6 с | 4 |
| ≫ Разгон | мяч соперника ускоряется, 8 с | 4 |
| ⌁ Глушилка | скиллы уходят на перезарядку, 10 с | 5 |
| ◍ Вампир | энергия супера соперника переходит вам | 5 |
| ⇊ Толчок | поле вздрагивает и оседает на ряд вниз | 6 |

В дуэли поля для мусора нет, поэтому «Сталь» и «Толчок» вместо рядов разгоняют
мяч в сторону жертвы. Заряженный мяч всегда виден по цвету — соперник
предупреждён.

## Таймер, статистика и доска почёта

Каждый уровень идёт с таймером, но он **не давит**: на жизни и прогресс время не
влияет вообще, оно только начисляет бонус к счёту за скорость. Быстрое
прохождение стоит до 1500 очков, медленное — почти ничего; у поздних уровней
норматив длиннее, потому что они плотнее.

**Статистика** ведётся по каждому уровню для каждого профиля: лучшее время,
лучший счёт, накопленный опыт, число зачисток и смертей. Отдельная таблица
сравнивает всех игроков — уровень профиля, общий опыт, опыт именно за уровни,
рекорд, прогресс кампании и число витков NG+.

**Доска почёта общая для всех запущенных копий игры на компьютере.** Результат,
поставленный в одном окне, появляется в соседнем сразу, без перезагрузки:
хранилище служит источником правды, а `BroadcastChannel` — мгновенным
уведомлением. Та же логика слияния позже ляжет на сетевой сервер — поменяется
только транспорт.

## Развилки

Кампания — не прямая линия, и билд внутри забега тоже.

**Развилка пути.** Каждые 10 уровней забег упирается в развилку: следующий
десяток перестраивается под выбранный маршрут — своя палитра кирпичей, своя
плотность, скорость и награды.

| Маршрут | Поля | Награда |
| --- | --- | --- |
| ⛓ Литейная | сталь, неразрушимые, взрывные; мяч медленнее | плотные уровни и много очков |
| ❉ Оранжерея | регенераторы, золото, подарки | +40% опыта |
| ☢ Пустошь | хаос-паттерны, разогнанный мяч | +50% к выпадению бонусов |

Выбранные маршруты пишутся в автосохранение, так что забег восстанавливается
ровно тем, каким его вели.

**Развилка билда.** На 5-м уровне мастерства вместо обычного усиления
предлагается специализация на весь забег. Она не только даёт мгновенный эффект,
но и втрое повышает шанс встретить в дальнейших драфтах усиления своей школы.

| Специализация | Что даёт |
| --- | --- |
| ↑ Артиллерист | штатный лазер, двойной урон выстрелов, +35% энергии супера |
| ✷ Элементалист | элементальные шары держатся вдвое дольше, +1 урон, +40% бонусов |
| ▭ Страж | +2 жизни и +2 барьера сразу, ракетка шире, мяч послушнее |

## Новая кампания и витки (New Game+)

Уровень профиля, опыт, суперы, рекорды и статистика живут отдельно от забега,
поэтому кампанию можно начинать заново сколько угодно раз, ничего не теряя.
Кнопка «Новая кампания» стартует чистый забег (автосохранение при этом
перезаписывается — об этом предупреждает подсказка).

Прохождение сотого уровня открывает следующий **виток**: за каждый виток мяч
быстрее на 8%, а опыт идёт с прибавкой 25%. Номер витка виден в главном меню,
и в него можно войти сразу с экрана победы.

## Настройки забега

На экране кампании перед стартом выбираются:

- **Жизни** — 1 (хардкор), 3, 5 или 9.
- **Скорость игры** — ×1, ×2 или ×3. Множитель ускоряет игровые часы целиком:
  мяч, ракетка, падающие бонусы и все таймеры — так что игра остаётся собой,
  просто быстрее. Переключается и на ходу клавишей `F`, текущее значение видно
  в HUD рядом с номером уровня.

Обе настройки запоминаются в профиле и действуют также в PvP-режимах.

## Управление

Во время игры курсор скрывается, а мышь **захватывается полем**: она не уезжает в
интерфейс браузера — ни к вкладкам, ни к закладкам — и не теряется за краем
экрана посреди розыгрыша. Захват берётся при входе в уровень и после закрытия
любой панели.

Единственный выход — `Esc`: он одновременно возвращает мышь и ставит игру на
паузу. (Браузер забирает `Esc` себе, чтобы отпустить указатель, поэтому игра
трактует само освобождение как нажатие паузы — иначе клавиша до неё не дошла бы.)
Мышь захватывается только там, где она управляет ракеткой: в кампании и коопе.

**Одиночная игра:** мышь или `A`/`D` (`←`/`→`) — ракетка, `Пробел` — запуск мяча
и выстрел лазером, `Shift` — суперудар, `1`/`2`/`3` — выбор усиления,
`F` — скорость игры, `Esc` — пауза.
Управляет то устройство, которым воспользовались последним:
нажали клавишу — ведёт клавиатура, двинули мышь — снова мышь.

**PvP:** игрок 1 — `A`/`D`, `W` (огонь), `S` (супер), усиления `1`/`2`/`3`;
игрок 2 — `←`/`→`, `↑` (огонь), `↓` (супер), усиления `8`/`9`/`0`.

**Гонка:** тот, чей ход, играет как в одиночной игре плюс `R` — щит от одной
входящей карты; на экране кубика и хода дальше пускает пробел или клик. Ждущие игроки бросают карты своим рядом клавиш: место 1 —
`Z X C`, место 2 — `B N M`, место 3 — `7 8 9`, место 4 — `4 5 6`, место 5 —
`, . /`, место 6 — `; ' \`. Ряды намеренно не пересекаются ни с ракеткой, ни с
выбором усилений, поэтому шесть человек помещаются за одной клавиатурой.

## Система опыта

Опыт даёт каждый разбитый кирпич; серия попаданий без потери мяча поднимает
множитель (до ×12, больше — с усилением «Серия»). Новый уровень мастерства
внутри забега останавливает игру и предлагает три усиления на выбор:
ширина и скорость ракетки, критический урон, магнит для бонусов, штатный лазер,
запасные жизни, нижний барьер и другие — всего 17 видов со стеками.

Опыт начисляется намеренно скупо (глобальный коэффициент `XP_RATE = 0.1` в
[progression.ts](src/core/progression.ts)): усиление — награда за длинную чистую
серию, а не за каждый экран.

После забега весь набранный опыт зачисляется в профиль (`localStorage`).
Уровень профиля открывает суперудары: «Разлом времени» с 3-го, «Сингулярность»
с 5-го.

## Элементальные шары

Отдельный класс бонусов перекрашивает мяч и меняет то, как он бьёт. Действуют
14–18 секунд, за две секунды до конца мяч начинает мигать белым.

| Шар | Цвет | Что делает |
| --- | --- | --- |
| Лава-болл | оранжевый | прошивает кирпичи насквозь и поджигает всё вокруг точки удара |
| Аква-болл | голубой | медленный и послушный, бьёт волной по соседям в ряду |
| Лазер-болл | зелёный | каждое попадание выпускает вверх два луча |
| Плазма-болл | фиолетовый | цепная молния на два ближайших кирпича |
| Войд-болл | индиго | тяжёлый: +2 урона, притягивает бонусы и доворачивает к кирпичам |

## Звук и музыка

Звуковые эффекты синтезируются в WebAudio прямо в коде
([sfx.ts](src/audio/sfx.ts)) — ни одного аудиофайла, ни загрузки, ни задержек;
высота звука разрушения растёт вместе с комбо.

### Как добавить свои треки

Музыки в репозитории нет — она подключается вашими файлами, и это делается в два
шага.

**1. Положите аудио в `public/music/.`** Подойдёт любой формат, который играет
браузер: `.mp3`, `.ogg`, `.m4a`, `.wav`. Имена — любые, но лучше без пробелов.

**2. Опишите их в `public/music/manifest.json`** (создайте файл, если его нет):

```json
{
  "tracks": [
    { "file": "menu.mp3", "title": "Standby", "scene": "menu" },
    { "file": "drive.mp3", "title": "Neon Drive", "scene": "game" },
    { "file": "duel.mp3", "title": "Duel", "scene": "versus" }
  ]
}
```

Перезагрузите страницу — музыка заиграет. Проверить, что игра видит треки, можно
в меню «Звук и музыка»: там показано название текущего и кнопка «Следующий трек».

| Поле | Что это |
| --- | --- |
| `file` | имя файла в `public/music/`, обязательно |
| `title` | как называть трек в меню; необязательно |
| `artist` | необязательно, для порядка |
| `scene` | `menu`, `game`, `versus` или `any` — где играет |

`scene` — `menu`, `game`, `versus` или `any`. Треков на сцену может быть
сколько угодно, игра берёт случайный и переходит к следующему по окончании. Без
манифеста музыка просто выключена. Громкость эффектов и музыки настраивается в
меню «Звук и музыка».

## Суперудары

Шкала копится от урона и подобранных бонусов. В PvP каждый удар одновременно
бьёт по сопернику:

| Супер | Своё поле | По сопернику |
| --- | --- | --- |
| Плазменный залп | 5 секунд плазмы из ракетки | ряд мусорных кирпичей |
| Метеор | горящие мячи прошивают кирпичи | разгон мяча на 8 секунд |
| Разлом времени | замедление + широкая ракетка | инверсия управления на 5 секунд |
| Сингулярность | чёрная дыра перемалывает кирпичи | помехи на экране на 6 секунд |

## Формат уровня

Уровень — это JSON, который можно править руками; каждая строка `rows` — ряд
из 12 символов:

```json
{
  "id": "user-abc",
  "name": "Крепость",
  "rows": ["xxnnnnnnnnxx", "xnttttttttnx"],
  "ballSpeed": 1.05
}
```

Коды кирпичей: `.` пусто, `n` обычный, `t` прочный (2 удара), `s` стальной (3),
`x` неразрушимый, `e` взрывной, `r` регенерирующий, `g` золотой (тройной опыт),
`p` подарок (гарантированный бонус), `b` мусорный (прилетает в PvP).

Против неразрушимых блоков есть два ответа: **сингулярность** перемалывает их
в своём радиусе, а **файрбол III ранга** пробивает насквозь. Регенератор
возрождается не бесконечно — три раза, каждый следующий медленнее, — и
генератор никогда не запирает его в кармане из неразрушимых.

Сгенерированные уровни до зоны хаоса **симметричны** — зеркало наводится
последним, уже после прорезания коридоров, чтобы поле выглядело нарисованным, а
не насыпанным. Хаос-уровни (81–100) намеренно остаются рваными.

## Устройство кода

```
src/core/     симуляция: арена, физика, кирпичи, бонусы, шары, опыт, суперы,
              генератор уровней, хранилище
src/render/   canvas-рендер, частицы, фон меню
src/game/     режимы: кампания, раздельный экран, дуэль, гонка, ввод,
              фиксированный шаг
src/editor/   редактор уровней
src/audio/    синтез звуков и музыкальный плеер
src/ui/       меню, выбор уровня, настройки звука, DOM-хелперы, стили
public/music/ ваши треки (см. README внутри)
```

Симуляция отделена от рендера и идёт фиксированным шагом 1/120 с с сидированным
генератором случайных чисел: при одинаковых входных данных результат
воспроизводится, поэтому обе половины PvP-матча честны, а сетевой режим можно
добавить поверх той же логики.
